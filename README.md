# SGT Technologies — Corporate Website

> **Tagline:** Build Beyond Limits.  
> **Brand Identity:** Premium, luxury, enterprise-grade technology company.  
> **Industry:** Software Development, IT Services, AI & Automation.

---

## 🌟 Overview

This repository contains the complete, modern, responsive website for **SGT Technologies**, a service-based technology consultancy providing custom software engineering, AI automation, and cloud infrastructure solutions.

### 🎨 Brand Aesthetics & Color Palette
- **Midnight Black (`#111111`)**: Primary backdrop establishing depth and prestige.
- **Champagne Gold (`#C8A96B`)**: Sophisticated metallic accent for active highlights and CTAs.
- **Warm Ivory (`#F7F2E8`)**: High-contrast, readable typography.
- **Pure White (`#FFFFFF`)**: Crisp primary headings.
- **Dark Gray (`#262626` / `#1A1A1A`)**: Surface elevation for cards and modals.

---

## 📑 Website Pages

1. **Home (`/`)**:
   - Dynamic Hero section with system architecture matrix showcase.
   - Comprehensive Services Overview featuring all 8 specialized domains.
   - 6 Core Value pillars ("Why Choose SGT Technologies").
   - Featured illustrative case studies with interactive case study modals.
   - 5-step engineering methodology lifecycle.
   - Lead generation CTA banner.

2. **Services (`#/services`)**:
   - Deep-dive for each of the 8 services with structured 3-pillar breakdown:
     - **Problems It Solves**
     - **Business Benefits**
     - **Typical Use Cases**
   - Core technologies breakdown and direct inquiry CTAs.

3. **Projects (`#/projects`)**:
   - Responsive portfolio grid with domain filters.
   - Interactive case study view modal detailing architecture, challenges, and deployed stacks.

4. **About Us (`#/about`)**:
   - Official brand mission, vision, and core values.
   - Technology philosophy and commitment to engineering craftsmanship.

5. **Careers (`#/careers`)**:
   - Engineering culture pillars and work philosophy.
   - Talent network section with general candidate introduction form.

6. **Contact (`#/contact`)**:
   - Full enquiry form with client-side validation, accessible labels, anti-spam honeypot, and loading/confirmation states.
   - Office hours, email, phone, and direct location placeholders.

---

## 🛠️ Tech Stack & Architecture

- **Frontend Core:** React 19, JavaScript (ESNext), HTML5
- **Build Tool:** Vite
- **Styling:** Modular Vanilla CSS with individual CSS files for every page and component
- **Typography:** Manrope (Headings), Inter (Body)
- **Icons:** Lucide React & inline custom SVGs
- **Routing:** Hash-based client routing (`#/home`, `#/services`, etc.)

## 🚀 Getting Started

### Prerequisites
- Node.js (v18 or later recommended)
- npm or yarn

### Installation
```bash
# Clone the repository
git clone https://github.com/sujit-21/sgt_ui-ux-.git

# Navigate into the project directory
cd sgt_ui-ux-

# Install dependencies
npm install

# Start the local development server
npm run dev
```

### Build for Production
```bash
npm run build
```
The optimized bundle will be compiled into the `dist/` directory.
